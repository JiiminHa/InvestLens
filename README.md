# InvestLens

테마 중심 투자 학습 코치 MVP.

## 실행 방법

1. `.env` 파일에 `UPSTAGE_API_KEY=<실제 키>` 설정 (Git 제외)
2. `npm install`
3. `npm run web` — 서버 실행 (기본 `localhost:3000`)
4. 브라우저에서 `http://localhost:3000` 접속
5. `npm test` — 타입체크(`tsc --noEmit`) + Golden Path 테스트 실행

## 화면 구성

화면은 세 영역으로 나뉜다.

- **왼쪽 패널**: 관심 테마 목록과 과거 학습 노트, 학습한 투자 렌즈(판단 기준) 목록
- **가운데**: 실제 대화가 이루어지는 영역. 테마를 고르면 시장 장면(fixture)과 기업 리포트 붙여넣기 입력란(선택)이 보인다. 학습을 시작하면 접을 수 있는 시장 장면과 코치-사용자 대화 목록, 답변 입력창이 가운데에 표시된다.
- **오른쪽 패널**: 코치 패널. 학습 시작 전에는 "학습 시작" 버튼, 학습 중에는 "판단 정리" 패널(판단 입력, 결정 선택, 저장 후 학습 완료)이 열린다.

즉 대화는 가운데에서, 판단과 완료 정리는 오른쪽에서 이루어진다.

## 핵심 흐름

1. **테마 선택** — 왼쪽에서 관심 테마 선택 (선택과 동시에 대표 기업 사례·시장 장면이 가운데에 표시됨)
2. **시장 장면 확인 또는 기업 리포트 붙여넣기** — 가운데에서 fixture 기반 시장 장면을 보거나, 실제 기업 리포트 텍스트를 직접 입력 (선택사항)
3. **코치와 대화** — 오른쪽 "학습 시작" 후 가운데에서 코치 질문과 사용자 답변이 오감
4. **판단 정리** — 오른쪽 "판단 정리하고 끝내기" 패널을 열어 내 판단과 결정(투자함/투자하지 않음/공부만 함) 입력
5. **학습 완료 요약 저장** — 완료 요약을 세션으로 저장하고, 오른쪽 패널에 요약·finalMessage 표시
6. **과거 학습과 재연결** — 저장된 과거 학습 맥락이 이후 새로운 학습 세션의 코치 프롬프트에 반영됨

## 리포트 붙여넣기 기능

기업 리포트 텍스트를 입력하면, 세션 시작 시 1단계 LLM 호출이 해당 리포트에서 투자 렌즈에 필요한 데이터포인트만 추출한다. 이렇게 추출된 데이터 풀(`dataPool`)은 세션 전체(모든 턴의 코치 프롬프트 + 완료 요약)에서 재사용된다. 추출은 세션당 1회만 수행하며, 같은 세션에서 다시 추출하지 않는다.

리포트 텍스트를 넣지 않으면 기본 시장 장면(fixture) 경로가 사용되며, 이 장면은 하드코딩된 미검증 mock 데이터이다.

## 알려진 한계

- 리포트를 넣지 않으면 기본 시장 장면은 하드코딩된 미검증 mock 데이터이며, 화면과 코치 프롬프트 양쪽에 그렇게 표시된다("코치 미연결 — 예시 응답" 배지, 화면의 "예시 장면" 안내).
- 실시간 시세·뉴스 연동은 없다. 외부 API 연동 없이 로컬 fixture와 사용자가 입력한 리포트 텍스트만 사용한다.
- 데이터는 메모리 저장소(InMemoryStore)에 있어 서버를 재시작하면 사라진다.
- 투자 후보 상태 추적(더 공부/관찰/투자 후보/보류 등)은 현재 구현돼 있지 않다. `completeSessionWithSummary`에 후보 상태 저장 로직이 빠져 있으며, 데모/제출에 필수는 아니다.
- 코치 응답이 질문 형태면 `readyToComplete`가 false로 남아, 답변을 몇 번 보내도 오른쪽 완료 패널이 자동 열리지 않는다. 현재는 "판단 정리하고 끝내기"가 항상 노출되어 있어 사용자가 수동으로 완료 진입할 수 있다.
