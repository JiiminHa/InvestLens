# InvestLens

InvestLens는 기업 분석 결론이나 종목 추천을 대신 제공하는 서비스가 아닙니다. 기업과 시장 장면에 투자 렌즈 하나를 적용해 사용자가 직접 판단하도록 돕고, 그 판단 경험을 다음 학습에서 다시 활용하는 **AI 투자 학습 에이전트**입니다.

현재 MVP는 학습용 fixture와 사용자가 제공한 기업 리포트 텍스트를 지원합니다.

## 해결하려는 문제

초보 투자자는 많은 뉴스와 분석을 접하지만, 어떤 기준으로 판단해야 하는지 배우기 어렵습니다. 기존 투자 정보 서비스가 분석 결과를 제공하는 데 집중한다면, InvestLens는 다음 경험에 집중합니다.

- 현재 기업 장면에 필요한 판단 기준 하나를 배웁니다.
- AI의 결론을 받는 대신 사용자가 직접 판단합니다.
- 사용한 투자 렌즈와 판단을 학습 기록으로 남깁니다.
- 과거에 배운 렌즈를 새로운 기업에 다시 적용합니다.

핵심은 **분석 결과 제공이 아니라 투자 판단 능력의 축적과 재사용**입니다.

## 핵심 사용 흐름

1. 관심 테마와 기업 사례를 선택합니다.
2. 학습용 시장 장면을 확인하거나 기업 리포트 텍스트를 붙여넣습니다.
3. AI 코치가 현재 장면에 필요한 투자 렌즈 하나와 판단 질문을 제시합니다.
4. 사용자가 직접 답하면 코치가 답변을 바탕으로 후속 질문을 이어갑니다.
5. 사용자가 최종 판단과 결정을 정리하면 렌즈 숙련도와 판단 기록이 저장됩니다.
6. 다음 기업 학습에서 과거 렌즈와 판단 경험을 다시 활용합니다.

예를 들어 Tesla 학습에서 사용한 `기대 vs 실제` 렌즈를 이후 NVIDIA 장면에 다시 적용하며, 사용자가 같은 판단 기준을 다른 기업에서도 활용하도록 돕습니다.

## AI 코칭 원칙

코치는 `.hermes/skills/beginner-stock-coach/SKILL.md`의 지침을 실제 system prompt로 사용합니다.

- 한 턴은 `시장 장면/숫자 → 투자 렌즈 하나 → 사용자 판단 질문`에서 멈춥니다.
- 앱이 특정 렌즈를 미리 선택하지 않습니다. Solar가 현재 장면과 과거 학습 맥락을 보고 렌즈를 선택합니다.
- 새 개념은 먼저 설명하고, 이미 배운 렌즈는 사용자가 직접 적용하게 합니다.
- 사용자의 답변을 대화 맥락으로 전달해 피드백과 다음 질문으로 이어갑니다.
- 종목을 대신 고르거나 매수·매도 결론을 내리지 않습니다.
- 확인되지 않은 숫자를 만들어내지 않습니다.

## 기업 리포트 처리

기업 리포트 텍스트를 입력하면 두 단계로 처리합니다.

```text
기업 리포트 텍스트
  → 1단계 Solar: actual, 기대·가이던스, 성장률 등 핵심 데이터 추출
  → 2단계 Solar: 투자 렌즈 선택과 판단 코칭
```

추출된 데이터 풀은 같은 세션의 후속 코칭과 완료 요약에서 재사용합니다. 리포트를 입력하지 않으면 미검증 학습용 fixture를 사용하며, 화면에 예시 데이터임을 표시합니다.

시스템은 사용자가 붙여넣은 문서가 공식 자료인지 자동 검증하지 않습니다. 공식 IR, SEC, DART 등 신뢰할 수 있는 1차 출처 사용을 권장합니다.

## 실행 방법

요구 사항:

- Node.js와 npm
- Upstage API Key

```bash
npm install
cp .env.example .env
```

`.env`에 키를 설정합니다.

```dotenv
UPSTAGE_API_KEY=your_api_key
```

로컬 서버를 실행합니다.

```bash
npm run web
```

브라우저에서 `http://localhost:3000`에 접속합니다.

테스트는 다음 명령으로 실행합니다.

```bash
npm test
```

현재 자동 테스트는 타입 검사와 mock 코치 기반의 세션 시작·완료, 렌즈 상태 저장, 실패 처리, 과거 학습 재연결을 검증합니다. 브라우저 UI와 실제 Solar 리포트 흐름은 별도로 확인해야 합니다.

## 현재 구현 범위

- 테마와 기업 사례 선택
- 학습용 시장 장면과 mock 상태 표시

- 관련 과거 학습이 식별된 경우 연결 관계 표시

## MVP 범위

현재 MVP는 학습용 fixture 또는 사용자가 제공한 기업 리포트 텍스트를 기반으로 동작합니다. 자동 데이터 수집, 출처 검증, 영구 저장은 후속 개발 범위입니다.
